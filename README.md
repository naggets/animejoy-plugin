# AnimeJoy для Lampa

Плагин-источник «Онлайн» для [Lampa](https://lampa.mx): смотрит аниме с русскими субтитрами с сайта **animejoya.ru** (AnimeJoy) прямо из карточки тайтла.

## Возможности

- Кнопка **«AnimeJoy»** в карточке аниме (рядом с «Онлайн»)
- Автопоиск тайтла по названию карточки (RU / EN / оригинальное, с учётом сезона)
- Список серий, ручной выбор тайтла (если нашлось несколько) и плеера
- Прямые ссылки на видео (mp4) с субтитрами:
  - **CDA** — все качества 360p–1080p через публичный API
  - **AllVideo** (fsst.online / incvideo) — 360p/720p
  - **Sibnet** — может требовать IP РФ
  - Kodik — пока не поддерживается
- Полный плейлист серий в плеере Lampa (переключение серий, выбор качества)
- Метки прогресса просмотра (процент / ✓) через стандартный Timeline Lampa

## Установка

1. В Lampa: **Настройки → Расширения → Добавить плагин**
2. Укажите URL файла `animejoy.js` из этого репозитория (raw-ссылка):
   ```
   https://raw.githubusercontent.com/naggets/animejoy-plugin/main/animejoy.js
   ```
3. Зайдите в **Настройки → AnimeJoy** и заполните:
   - **Домен / зеркало** — актуальное зеркало (по умолчанию `https://animejoya.ru`)
   - **Логин / Пароль** — учётная запись animejoya.ru (требуется: поиск и страницы тайтлов закрыты для гостей)
   - Нажмите **«Проверить вход»**

## Настройки

| Параметр | Описание |
|---|---|
| Домен / зеркало | Актуальный домен AnimeJoy |
| Логин / Пароль | Авторизация на animejoya.ru |
| Проверить вход | Тест авторизации |
| Приоритет плеера | Авто / CDA / AllVideo / Sibnet |
| Качество видео | 1080p / 720p / 480p / 360p / Максимальное |

## Как это работает

1. Плагин авторизуется на сайте (стандартная DLE-форма, куки)
2. Ищет тайтл через `POST /index.php?do=search`
3. Со страницы тайтла берёт `data-news_id`, затем запрашивает плейлист: `GET /engine/ajax/playlists.php?news_id=...&xfield=playlist`
4. Из embed-ссылок плееров извлекает прямые mp4 и отдаёт в плеер Lampa

## Разработка

Тесты парсеров (на реальных зафиксированных ответах сайта):

```bash
node tests/test_parse.js
```

Требуется Node.js. Зависимостей нет.

## Известные ограничения

- Kodik-плеер не поддерживается (сложная защита ссылок); используйте CDA/AllVideo/Sibnet — это те же серии с теми же субтитрами
- Sibnet может быть недоступен вне РФ
- При смене зеркала сайта просто обновите домен в настройках плагина
